💻 CS Matura Prep

Repository containing programming materials, exercises, and homework assignments designed to help  prepare for the Polish Computer Science Matura Exam.

The goal of this repository is to develop programming skills step by step, starting from basic concepts and gradually progressing to more advanced problems.

📁 Repository Structure

📘 Intro

Contains materials and exercises covered during lessons.

Topics include:

* Variables and data types
* Input and output operations
* Conditional statements (if, elif, else)
* Loops (for, while)
* Lists and dictionaries
* Functions
* Algorithms and problem-solving techniques

📝 Homework

Contains homework assignments designed to reinforce concepts learned during lessons.

Each assignment helps students practice programming independently and develop logical thinking and problem-solving skills.
